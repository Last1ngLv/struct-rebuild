# struct-rebuild

Rebuild limpio del proyecto Warcraft III `struct`.

## Fase 1 objetivo

- Selección de héroe.
- Contador prewave.
- Transcurso de wave + rest time.
- Victoria global al superar la última ronda.
- Revivir / vidas base.
- Misiles base.
- IA básica de ataque para enemigos.
- Texttags de vida para héroes/enemigos, sin sistemas locales peligrosos.
- Multiboard como UI principal temporal.

## Fuera de Fase 1

- MenuClient.
- Tender UI/audio local.
- Tienda.
- Árbol de mejoras.
- Mutaciones.
- Spells enemigos complejos.
- Sistemas experimentales de `Pruebas`.

## Regla de trabajo

No ejecutar build automáticamente desde Codex. El build se valida manualmente desde el entorno del mapa/editor.
